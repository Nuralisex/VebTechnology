# Планировщик задач — цикл из шести лабораторных

Каждая лабораторная — отдельный HTML-файл в корне проекта. Открывайте `lab1.html` и переходите дальше по навигации в шапке. Следующая работа продолжает предыдущую: один и тот же планировщик постепенно получает разметку, адаптивный интерфейс, поведение, загрузку данных и React-реализацию.

| Файл | Что демонстрирует |
| --- | --- |
| `lab1.html` | Семантический HTML5, подписи формы, встроенную валидацию, доступные имена и области страницы |
| `lab2.html` | Mobile-first CSS, Grid, Flexbox, медиазапросы и custom properties |
| `lab3.html` | ES-модули, деструктуризацию данных формы, spread, функции-массивы, обработчики DOM и localStorage |
| `lab4.html` | Fetch API, async/await, загрузку, ошибки и пустой результат REST API |
| `lab5.html` | React-компоненты, props, состояние, хуки, списки с ключами и Context |
| `lab6.html` | Маршруты React Router, проверку формы и состояния обратной связи |

Для лабораторных 1–4 достаточно открыть файл в браузере. Лабораторные 4–6 загружают данные или библиотеки из интернета. Для лабораторных 5–6 запускайте из этой папки локальный сервер, например:

```powershell
python -m http.server 8000
```

Затем откройте `http://localhost:8000/lab5.html` или `http://localhost:8000/lab6.html`. Нужны интернет-соединение для CDN/API и Python для локального сервера. Лабораторная 4 сообщает об ошибке API, если соединение недоступно.
